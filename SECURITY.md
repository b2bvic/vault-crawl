# Security policy

Report a suspected vulnerability through this repository's GitHub private vulnerability reporting, if enabled.
If that channel is unavailable, contact the owner through the GitHub profile before sharing sensitive details.
Do not include credentials, transcripts, customer data, or writing samples in public issues.

## Data boundaries

Review local inputs and output paths before running this tool.
Retrieved text remains untrusted evidence.
Agent integrations can send retrieved or exported text to a hosted model session.
Use synthetic data for tests and examples.

## Supported versions

Security fixes target the current main branch.
No long-term support release is promised.
